라이더 로그 — 포그라운드 서비스 위치 권한 사용 시연

패키지 kr.riderlog.app · 권한 android.permission.FOREGROUND_SERVICE_LOCATION
Demonstration of FOREGROUND_SERVICE_LOCATION usage for Google Play review.

이 권한을 쓰는 이유

배달 라이더가 운행 중 이동한 거리와 시간을 자동으로 기록하기 위해서입니다. 라이더는 운행 중 휴대폰을 거치대에 두고 다른 앱(배차 앱, 내비게이션)을 쓰므로, 앱이 화면 앞에 없는 동안에도 위치를 받아야 주행거리가 끊기지 않습니다. 이 거리는 종합소득세 신고 시 차량 관련 필요경비의 근거가 됩니다.

영상에서 확인하실 수 있는 것

1사용자가 직접 시작합니다. 홈 화면의 「운행 시작」 버튼을 눌러야만 서비스가 뜹니다. 앱 실행만으로는 위치를 받지 않습니다.
2상시 알림으로 고지합니다. 「운행 기록 중 · 경로는 이 기기에만 저장됩니다」 알림이 서비스가 도는 내내 유지됩니다.
3앱을 벗어나도 알림이 유지됩니다. 홈으로 나간 뒤에도 알림이 그대로 있어, 사용자가 기록 중임을 항상 알 수 있습니다.
4사용자가 언제든 끝냅니다. 「운행 종료」를 누르면 서비스가 멈추고 알림이 즉시 사라집니다.
영상은 Android 에뮬레이터에서 촬영했습니다.
에뮬레이터에는 실제 GPS 이동이 없어 화면의 주행거리가 0으로 표시되고 「위치를 잡는 중…」이 유지됩니다. 권한 사용 방식 — 사용자가 직접 시작하고, 상시 알림으로 고지하며, 사용자가 끄면 즉시 멈춘다 — 은 영상 그대로입니다.

Recorded on an Android emulator, which has no real GPS movement, so the distance reads 0. The permission behaviour shown — user-initiated start, persistent foreground notification, immediate stop on user action — is unmodified.

선언하지 않은 것

  • ACCESS_BACKGROUND_LOCATION 을 선언하지 않습니다. 위치는 포그라운드 서비스가 도는 동안에만 받습니다.
  • 위치를 서버로 보내지 않습니다. 이 앱에는 서버가 없고 회원가입도 없습니다. 경로는 기기 내부 데이터베이스에만 저장됩니다.
  • 위치를 제3자에게 공유하지 않습니다. 광고 SDK 에 전달되지 않으며, 지도 표시에도 기기의 현재 위치를 넘기지 않습니다.
  • 권한을 거부해도 앱의 나머지 기능은 정상 동작하며, 주행거리는 직접 입력할 수 있습니다.
